📖 Glossário Completo

Todos os termos técnicos explicados de forma simples

Termos Básicos Iniciante

HTML

O que é: Estrutura de uma página web
Analogia: Os tijolos de uma casa

CSS

O que é: Estilo visual da página
Analogia: A pintura e decoração da casa

JavaScript

O que é: Interatividade da página
Analogia: A eletricidade que faz tudo funcionar

Código

O que é: Instruções para o computador
Exemplo: Como uma receita de bolo

Tag

O que é: Marcação em HTML
Exemplo: <h1>Título</h1>

Atributo

O que é: Propriedade de uma tag
Exemplo: class="botao"

Elemento

O que é: Parte da página (botão, texto, imagem)
Tipos: Botões, inputs, divs

Função

O que é: Bloco de código reutilizável
Exemplo: Calcular soma de dois números

Termos Intermediários Intermediário

API

O que é: Interface para comunicação entre sistemas
Uso: Conectar seu site com serviços externos

Endpoint

O que é: URL específica de uma API
Exemplo: /api/usuarios/buscar

JSON

O que é: Formato de dados estruturado
Uso: Trocar informações entre sistemas

Framework

O que é: Conjunto de ferramentas prontas
Exemplos: React, Vue.js, Bootstrap

Biblioteca

O que é: Código pronto para reutilizar
Exemplos: jQuery, Lodash, Axios

Async/Await

O que é: Forma de lidar com operações demoradas
Uso: Carregar dados sem travar a página

Promise

O que é: Promessa de resultado futuro
Uso: Requisições HTTP, operações assíncronas

DOM

O que é: Document Object Model
Uso: Manipular elementos da página com JS

Termos Avançados Avançado

Webhook

O que é: Notificação automática entre sistemas
Uso: Receber eventos em tempo real

OAuth

O que é: Protocolo de autenticação
Uso: Login com Google, Facebook

SSR

O que é: Server-Side Rendering
Uso: Renderizar páginas no servidor

CI/CD

O que é: Integração e Deploy Contínuo
Uso: Automatizar testes e publicações

WebSocket

O que é: Comunicação bidirecional em tempo real
Uso: Chats, notificações live

Microservices

O que é: Arquitetura de serviços independentes
Uso: Escalar partes específicas do sistema

GraphQL

O que é: Linguagem de consulta para APIs
Uso: Buscar apenas dados necessários

Edge Computing

O que é: Processamento próximo ao usuário
Uso: Reduzir latência e melhorar performance
