Templates testados e aprovados para diferentes situações

💡 Como Usar

Clique no botão "Copiar" em qualquer prompt abaixo e cole na sua IA favorita (ChatGPT, Claude, etc). Adapte os valores entre [COLCHETES] para seu caso específico!

🎨 Landing Page

Crie uma landing page HTML completa para a CobHub com estas especificações: ESTRUTURA: - Header fixo com logo COBHUB e menu - Hero section com título impactante - Seção de benefícios (3 cards) - Call-to-action com botão principal - Footer com informações de contato ESTILO (IMPORTANTE): - Fundo: #0A0A0A - Cor primária: #43B8FE - Cor secundária: #6861FF - Fonte: 'Montserrat' para tudo - Títulos em ExtraBold (800) - Botão com gradiente: linear-gradient(135deg, #6861FF, #43B8FE) FUNCIONALIDADES: - Responsivo para mobile - Animações suaves ao scroll - Hover effects nos botões - Formulário de contato funcional Por favor, crie o código HTML completo com CSS embutido.

📊 Dashboard

Crie um dashboard web para a CobHub com: LAYOUT: - Sidebar lateral com navegação - Header superior com nome do usuário - Área principal com cards de métricas - Gráficos de dados (usar Chart.js) - Tabela de dados recentes CORES COBHUB: - Background: #0A0A0A - Sidebar: #2D2D2D - Cards: rgba(255,255,255,0.03) - Bordas: rgba(255,255,255,0.1) - Destaques em #43B8FE e #6861FF COMPONENTES: - Cards com ícones e números grandes - Gráfico de linha com gradiente - Tabela estilizada - Botões de ação com gradiente INTERATIVIDADE: - Menu responsivo (hamburguer no mobile) - Tooltips nos gráficos - Filtros de data - Exportação de dados Use HTML, CSS e JavaScript vanilla. Inclua CDN do Chart.js.

📜 Automação Google Sheets

Crie um script Google Apps Script que: FUNCIONALIDADE: - Leia dados de uma planilha específica - Processe e valide os dados - Faça cálculos automáticos - Envie email com relatório - Registre log de execução ESTRUTURA DO CÓDIGO: - Função principal com try/catch - Funções auxiliares bem documentadas - Constantes no início do código - Comentários explicando cada parte VALIDAÇÕES: - Verificar se a planilha existe - Validar formato dos dados - Tratar erros graciosamente - Retornar mensagens claras ESTILO: - Código limpo e organizado - Nomes de variáveis descritivos - Use const/let apropriadamente - Adicione exemplos de uso Por favor, crie o código comentado linha por linha para iniciantes.

🔌 API Integration

Crie uma integração com API externa: REQUISITOS: - Função para fazer requisição GET - Função para fazer requisição POST - Tratamento de erros da API - Retry logic em caso de falha - Cache de respostas para otimização SEGURANÇA: - Não expor API keys no código - Usar variáveis de ambiente - Validar entrada do usuário - Sanitizar dados antes de enviar ESTRUTURA: - Classe ou objeto com métodos - Async/await para requisições - Promise.all para múltiplas requisições - Timeout para requests longos RETORNO: - JSON padronizado - Status codes apropriados - Mensagens de erro claras - Dados formatados Use JavaScript moderno (ES6+) e inclua exemplos de uso.
